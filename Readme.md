# Cute Ghost 👻 — المرحلة الأولى

تطبيق أندرويد (Kotlin) يعرض شبحًا لطيفًا بخلفية شفافة يطفو فوق التطبيقات الأخرى.

## المزايا
- شاشة رئيسية عربية: «إظهار الشبح» و«إخفاء الشبح».
- طلب صلاحية «الظهور فوق التطبيقات» وتوجيهك إلى إعدادات أندرويد.
- نافذة عائمة شفافة (`TYPE_APPLICATION_OVERLAY`).
- طفو ناعم، وعند اللمس: ارتداد وتغيّر في تعبير الوجه.
- سحب الشبح بالإصبع، ويُحفظ آخر موضع ويُستعاد عند إظهاره من جديد.
- لا كاميرا ولا ميكروفون ولا موقع ولا جهات اتصال، ولا تسجيل دخول ولا إعلانات.

## الإعداد (من الهاتف فقط)
1. أنشئ مستودعًا جديدًا على GitHub (Repository) باسم `CuteGhost`.
2. أضف كل ملفات المشروع بمساراتها نفسها (Add file ← Create new file، واكتب المسار كاملًا في خانة الاسم مثل `app/src/main/AndroidManifest.xml` ثم الصق المحتوى).
3. تأكد من وجود الملف `.github/workflows/build.yml`.
4. بمجرد حفظ الملفات في الفرع `main` يبدأ البناء تلقائيًا.

## البناء وتنزيل الـ APK
1. افتح تبويب **Actions** في المستودع.
2. اختر آخر تشغيل لـ **Build APK**، وانتظر العلامة الخضراء (دقيقتان إلى خمس تقريبًا).
3. لإعادة البناء يدويًا: Actions ← Build APK ← **Run workflow**.
4. في أسفل صفحة التشغيل، قسم **Artifacts**، نزّل `CuteGhost-debug-apk` (يُنزَّل ملف ZIP بداخله `app-debug.apk`).
5. فك الضغط ثم ثبّت الـ APK (قد يطلب أندرويد السماح للمتصفح أو مدير الملفات بتثبيت التطبيقات من مصادر غير معروفة).

## أول تشغيل
1. افتح Cute Ghost واضغط **إظهار الشبح**.
2. سيفتح التطبيق إعدادات أندرويد: فعّل «السماح بالظهور فوق التطبيقات الأخرى» ثم ارجع.
3. إن كان الخيار معطّلًا (رمادي): من معلومات التطبيق ← النقاط الثلاث ← «السماح بالإعدادات المقيّدة»، ثم أعد المحاولة.
4. سيظهر الشبح تلقائيًا بعد منح الإذن. لإخفائه اضغط **إخفاء الشبح**.

## ملاحظات تقنية
- بيئة البناء: JDK 17 ـ Gradle 8.7 ـ Android Gradle Plugin 8.5.2 ـ Kotlin 1.9.24 ـ compileSdk 34 ـ minSdk 24.
- لا توجد مكتبات خارجية.
- النسخة الناتجة Debug موقّعة بمفتاح تجريبي تلقائي، ولا توجد أي مفاتيح أو كلمات مرور في المستودع.
- يعمل الشبح عبر خدمة أمامية (Foreground Service) بإشعار صامت حتى لا يوقفه النظام.
- لا يوجد `gradlew`؛ يستخدم الـ workflow إصدار Gradle 8.7 مباشرة عبر `gradle/actions/setup-gradle`.

## التحديث فوق النسخة المثبّتة (بدون حذف)
- يجب أن يرتفع رقم الإصدار (`versionCode` و`versionName` في `app/build.gradle.kts`) مع كل تحديث، وأقوم بذلك في كل مرة. يظهر رقم الإصدار أسفل الشاشة الرئيسية.
- يجب أيضًا أن تكون كل نسخة موقّعة بالمفتاح نفسه، وإلا يرفض أندرويد التحديث. لذلك أضف سرّين في GitHub (Settings ← Secrets and variables ← Actions): `GHOST_KEYSTORE_BASE64` و`GHOST_KEYSTORE_PASSWORD`.
- بعد إضافتهما ستُبنى كل النسخ بالمفتاح نفسه. احذف النسخة القديمة مرة واحدة فقط ثم ثبّت الجديدة، وبعدها تُحدَّث التطبيق فوقها مباشرة.
- المفتاح لا يُرفع إلى المستودع أبدًا، بل يُحفظ في Secrets فقط.

## الرفيق الصوتي للأطفال (3–5 سنوات)
- يضغط الطفل على الشبح فيستمع، ثم يحوّل كلامه العربي إلى نص (خدمة التعرف على الكلام في أندرويد)، ويرسل النص إلى نموذج Claude بتعليمات صارمة تناسب هذا العمر، ثم يقرأ الرد بصوت عربي (Google Text-to-Speech).
- أثناء الاستماع يكبر الشبح عينيه ويميل برأسه وينبض مع صوت الطفل، وأثناء التفكير ينظر للأعلى، وأثناء الكلام يحرّك فمه.
- الضغط على الشبح أثناء الاستماع ينهي التسجيل، وأثناء التفكير أو الكلام يوقفه.
- لا توجد شاشة لإدخال المفاتيح. تُضاف المفاتيح لاحقًا كسر في GitHub باسم `GHOST_AI_KEYS` (مفتاح واحد أو عدة مفاتيح مفصولة بفاصلة)، ثم يُعاد البناء. إن انتهى حد مفتاح أو رُفض ينتقل التطبيق إلى التالي. لا يوجد مفتاح داخل الكود ولا في المستودع، لكنه يُضمَّن في ملف APK عند البناء، فاستخدم مفاتيح مجانية أو محدودة فقط.
- قبل إضافة المفاتيح يقول الشبح عند الضغط عليه إنه ليس جاهزًا بعد.
- المحادثة تُحفظ في الذاكرة فقط (آخر 3 تبادلات) وتُنسى بعد 5 دقائق أو عند إخفاء الشبح. لا تُحفظ تسجيلات.
- المطلوب على الجهاز: خدمة Google للتعرف على الكلام، وبيانات الصوت العربي في Google Text-to-Speech، وإنترنت.
- تنبيه: التعرف على كلام الأطفال الصغار أقل دقة من الكبار، والردود مقيّدة بتعليمات صارمة لكنها ليست مضمونة بالكامل، فيُنصح بوجود الأهل قرب الطفل.

## إطعام الشبح
- كل ساعة (والوقت يُحفظ حتى لو أُخفي الشبح) يظهر فوق الشبح نص «أرجوك أطعمني، أنا جائع» وتحته صينية فيها تفاحة وموزة وكعكة كرتونية.
- يسحب الطفل الطعام بإصبعه إلى فم الشبح، فيأكله بحركة مضغ ووجه سعيد ويصغر الطعام تدريجيًا حتى يختفي. وإن أبعده الطفل عن الفم يتوقف الشبح عن الأكل ويعود الطعام إلى الصينية.
- بعد أن يأكل وجبة كاملة يشكر الطفل ثم تُغلق الصينية، وإن تُرك دون إطعام لثلاث دقائق تُغلق وحدها وتعود بعد ساعة.
- زر «جرّب الإطعام الآن» في الشاشة الرئيسية للتجربة دون انتظار ساعة.
- الرفيق الصوتي معطّل حاليًا (`Features.VOICE_ENABLED = false`)، وصلاحيتا الميكروفون والإنترنت غير مطلوبتين.
- معرّف التطبيق (applicationId) صار `com.companion.theghost`، أي أنه يُثبَّت كتطبيق جديد بجانب القديم.
