# برنامج Windows المرافق — قرار التقنية والتشغيل (المرحلة 3)

## التقنية المختارة: Go (مكتبة قياسية فقط)

| المعيار | Go | .NET (C#) | Rust |
|---|---|---|---|
| ملف تنفيذي واحد دون تثبيت Runtime على جهاز المستخدم | نعم | لا، إلا بنشر self-contained بحجم أكبر | نعم |
| اعتماديات خارجية | صفر | حزم NuGet للخدمة | حزم crates |
| الترجمة المتقاطعة إلى Windows من أي نظام | سهلة | أصعب | متوسطة |
| الشبكة المحلية والتشفير (TLS وmTLS) للمرحلة 4 | مضمّنة في المكتبة القياسية | متوفرة | عبر حزم |
| تعدد المهام لمحرك الفحص (المرحلة 5) | goroutines | Tasks | threads/async |

**السبب:** المطلوب برنامج صغير يعمل في الخلفية بأقل صلاحيات، يقدّم واجهة اتصال محددة، ويُنشر كملف واحد في GitHub Releases. Go يحقق ذلك دون أي مكتبة طرف ثالث، فتبقى سطح الهجوم وحجم الصيانة أقل ما يمكن. المرحلة 4 (اقتران آمن وتشفير) تستفيد من `crypto/tls` و`crypto/x509` الجاهزتين.

**المقايضة:** لا واجهة رسومية (نافذة أو أيقونة في شريط المهام) في هذه المرحلة. التحكم عبر سطر الأوامر، وحالة البرنامج تظهر في تطبيق الهاتف لاحقًا. يمكن إضافة أيقونة شريط لاحقًا إذا طُلبت.

## ما ينفذه هذا الإصدار (0.4.0)

- قراءة الأقراص **الثابتة** الحقيقية (السعة والمستخدم والمتاح) عبر `GetDiskFreeSpaceExW`. لا يقرأ أسماء ملفات ولا محتويات.
- قرص تعذّرت قراءته يُعرض بحالة `available: false` وسبب الخطأ بدل إسقاطه أو تخمين أرقامه.
- تشغيل في الخلفية، حالة، إيقاف، ومنع تشغيل نسختين.
- تشغيل تلقائي عند تسجيل دخول المستخدم عبر مفتاح `HKCU\...\Run` **بدون صلاحيات مدير**.
- سجل تقني (`diskati.log`) يحوي أحداثًا فقط: بدء، إيقاف، أخطاء. لا مسارات ولا أسماء ملفات. يُقتطع عند تجاوز 1MB.

## ما لا ينفذه بعد

- لا فحص (المرحلة 5)، ولا حذف أو حجر (المرحلة 6).
- الاتصال بالهاتف والاقتران منفذان في المرحلة 4: انظر `docs/SECURITY_PAIRING.md`. أوامر جديدة: `pair` و`devices` و`unpair` و`reset-cert`. منفذ الهاتف الافتراضي 47831 (يتغير بالمتغير `DISKATI_PORT`).
- نقطة التحكم الداخلية (`status` و`stop` و`disks` وإدارة الاقتران) تستمع على `127.0.0.1` فقط بمنفذ ورمز عشوائيين. قناة الهاتف منفصلة عنها (TLS على الشبكة الخاصة).
- الأقراص القابلة للإزالة والشبكية غير مشمولة في الإصدار الأول.

## التثبيت والتشغيل

1. نزّل `diskati.exe` من Artifacts في GitHub Actions (أو Releases لاحقًا).
2. ضعه في مجلد ثابت، مثل `C:\Users\<اسمك>\Diskati\`. لا تضعه في مجلد يُحذف أو يُنقل.
3. افتح PowerShell في المجلد نفسه وشغّل:

```
.\diskati.exe start      # تشغيل في الخلفية
.\diskati.exe status     # الحالة
.\diskati.exe disks      # الأقراص ومساحاتها
.\diskati.exe install    # التشغيل مع تسجيل الدخول
.\diskati.exe stop       # الإيقاف
.\diskati.exe uninstall  # إلغاء التشغيل التلقائي
```

قد يعرض Windows SmartScreen تحذيرًا لأن الملف غير موقّع رقميًا. هذا متوقع لبرنامج جديد، وتوقيع الشهادة الرقمية خارج نطاق هذه المرحلة.

## مجلد البيانات

`%LOCALAPPDATA%\Diskati` ويحتوي `control.json` (منفذ ورمز التحكم المحلي) و`diskati.log`. يمكن تغييره للاختبار بالمتغير `DISKATI_DATA_DIR`.

## الاختبار

- وحدات: `go test ./...` في المجلد `windows-companion` (تعمل على Linux وWindows).
- حقيقي على Windows: مهمة `build-windows` في GitHub Actions تشغّل الاختبارات، وتبني `diskati.exe`، وتنفذ `start` ثم `status` ثم `disks` ثم `stop` على جهاز Windows فعلي وتطبع ناتج الأقراص الحقيقية في السجل.
