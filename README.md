# ديسكاتي — Diskati

تطبيق Android لإدارة مساحة تخزين كمبيوتر Windows من الهاتف.

- اسم الحزمة (ثابت): `com.diskati.pcmanager`
- الحالة: **المرحلة 4 — الاقتران والاتصال الآمن**. أقراص الكمبيوتر حقيقية بعد الربط، والباقي (فحص، حذف) ما زال تجريبيًا.
- المرحلة 3: برنامج Windows المرافق في `windows-companion/` (Go)، انظر `docs/WINDOWS_COMPANION.md`.
- المرحلة 4: اقتران واتصال آمن بين الهاتف والكمبيوتر، انظر `docs/SECURITY_PAIRING.md`.
- الواجهة: Jetpack Compose، عربية RTL، وضع ليلي تلقائي. كل الأرقام والملفات المعروضة تجريبية وموسومة بذلك داخل التطبيق.

## البناء
البناء يتم عبر GitHub Actions (`.github/workflows/build.yml`) وينتج APK تجريبيًا
في قسم Artifacts. هذا بناء debug بتوقيع مؤقت لا يصلح لتحديث نسخة موقّعة سابقًا.

## الأسرار
لا تُرفع إلى المستودع: ملفات keystore، كلمات المرور، `google-services.json`.
تُحفظ في GitHub Secrets عند الحاجة (المرحلتان 7 و8).
